# リアルタイム温湿度監視システム

Raspberry Pi と BME280 センサーを活用し、研究室やオフィスなどの室内環境をリアルタイムに一元監視できるシステムです。

ローカルの大型モニター、本体の小型LCD、そしてネットワーク経由のWebブラウザの3箇所へ、センサーの値を即座に反映するリアルタイム同期によって、環境データを低遅延で配信します。

※**【デモモード搭載】**
本リポジトリはRaspberry Piやセンサーがない環境（Mac/Windows等）でも、自動的にモックデータ（--.-℃ / --.-%）を生成して起動するよう設計されています。実機環境がない方でも手軽にUIや挙動の動作確認が可能です。

## 主な特徴とこだわり

### 1. 3つの出力媒体への完全なリアルタイム同時同期
- **Webインターフェース (Flask)**: 同一ネットワーク内のPCやスマホからブラウザ経由で確認可能。
- **デスクトップGUI (Tkinter)**: 研究室内の大型モニター等にフルスクリーンで常時表示することを想定。
- **キャラクタLCD (I2C接続)**: ラズパイ本体のミニディスプレイへコンパクトに出力。

### 2. Server-Sent Events (SSE) による通信の最適化とリアルタイム同期
フロントエンド側で定期的にリクエストを送り続ける「ポーリング通信」ではなく、サーバー側で温湿度の変化を検知した瞬間のみデータを送信する「プッシュ通信（SSE：Server-Sent Events）」を採用しています。
画面の時刻更新（1秒周期のローカル処理）と、データのプッシュ受信を明確に切り分けることで、ネットワーク帯域と Raspberry Pi へのCPU負荷を最小限に抑えつつ、リアルタイム同期を実現しています。

### 3. 環境を選ばないエラーハンドリング
I2Cバスやセンサー（`smbus2`）の接続有無を起動時に自動判定します。ラズパイ以外の環境で実行された場合は、システムがクラッシュすることなく自動的に「デモモード」へと切り替わり、画面表示やWebサーバー機能が正常に動作し続けます。

## 技術的な課題 

### 1. **センサー監視スレッドの一元化と最適化**
  現状は `humidity.py`（センサーの定期読み取りスレッド）と `watcher.py`（値の変更監視スレッド）で、それぞれ独立したワーカースレッドが動いています。このポーリング処理を1つに統合し、よりシンプルでオーバーヘッドの少ないイベント駆動型アーキテクチャへリファクタリングします。
### 2. **WSGIサーバーの導入 (プロダクション対応)**
  現在は Flask の開発用サーバー (`app.run()`) をマルチスレッドで起動していますが、長期間の連続稼働における安定性を高めるため、Gunicorn や Waitress などの WSGI サーバーを用いた本格的なデプロイ構成をサポートする予定です。
### 3. **Tkinter GUIのレスポンシブ対応強化**
  フルスクリーン表示用のGUIにおいて、現在は起動時に一度だけ画面サイズを取得してフォントサイズを決定しています。ウィンドウサイズが途中で変更された場合 (`<Configure>` イベント等) にも、動的にフォントがリサイズされるようUIを改善します。

## ディレクトリ構成

```text
.
├── main.py          # システムのメインエントリーポイント（各スレッドの統括）
├── humidity.py      # BME280センサー制御・データ取得ロジック（モック機能内蔵）
├── watcher.py       # センサー値の変更監視・コールバック通知の制御
├── monitor.py       # Tkinterによる大型モニター用フルスクリーンGUI
├── lcd.py           # I2C接続キャラクタLCD（AQM0802等）の制御
├── templates/
│   └── index.html   # Web表示用UI（SSEによるリアルタイムプッシュ通信実装）
└── static/
    └── browseondo.css # Web UI用スタイリングシート
```

## 使い方

### 1. リポジトリのクローン
```bash
git clone https://github.com/hidehito-kawashima/room-temperature-monitor.git
cd room-temperature-monitor
```

### 2. 依存ライブラリのインストール
```bash
pip install Flask
```
※ ラズベリーパイ環境で動かす場合は、必要に応じて `smbus2` もインストールしてください。
```bash
pip install smbus2
```

### 3. アプリケーションの起動

#### Mac / Windows などのPCで動かす場合（デモモード）
GUIモニターをスキップし、Webブラウザ側での挙動を確認する場合は以下のコマンドを実行します。
```bash
python main.py --no-monitor
```
起動後、ブラウザで `http://127.0.0.1:5000` にアクセスすると、1秒ごとに同期する時計とデモ用の温湿度データ（--.-℃ / --.-%）が表示されます。

#### Raspberry Pi 実機で動かす場合（フル機能モード）
センサーや各種ディスプレイを接続したラズパイ上で以下を実行します。
```bash
python main.py
```
自動的に大型モニター用GUIがフルスクリーンで起動し、センサーから取得したリアルタイムの室内環境値が表示されます。

## オプション引数 (Arguments)

`main.py` は以下のオプションに対応しています。

| 引数 | 説明 |
| :--- | :--- |
| `--port` | Webサーバーのポート番号を指定（デフォルト: 5000） |
| `--no-monitor` | Tkinterの大型モニターGUIを起動しない（Web機能のみ使用する際） |
| `--browser` | 起動時に自動でブラウザを開く |
| `--lcd` | LCDにも表示する |
| `--debug` | デバッグモードで起動する |
